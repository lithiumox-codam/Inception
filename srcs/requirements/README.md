# Requirements Directory

This directory contains the configuration files for each service in the Inception project:

## Navigation
- [⬆️ Project Root](../README.md)
- [⬇️ MariaDB Configuration](mariadb/README.md)
- [⬇️ Nginx Configuration](nginx/README.md)
- [⬇️ WordPress Configuration](wordpress/README.md)

Each subdirectory contains:
- **Dockerfile**: Defines how to build the container image
- **tools/**: Contains initialization scripts
- **conf/**: Contains configuration files for the service
